# nolanpix.github.io

Source for <https://nolanpix.github.io> — the personal site / open notebook of
**Nolan Pierce**, a digital IC physical design engineer (P&R, CTS, STA, signoff).

Static HTML, no build step. Structure:

- `index.html` — home: chip-floorplan hero (site map), latest notes, repos, about.
- `notes/*.html` — individual note pages, generated from `tools/gen_notes.py`.
- `404.html` — the page GitHub Pages serves for any missing path (root-relative links),
  generated by `tools/gen_notes.py`.
- Contents rail — every page carries the same quiet list of sections, notes and tools,
  shown in the left margin on screens 1280px and wider (it replaces the top-bar section
  links there). Written by `tools/gen_notes.py`; in `index.html` it lives between the
  `rail:start` / `rail:end` markers — do not edit inside them.
- `assets/style.css` — shared "tapeout terminal" styles. Dark by default; light theme via
  `data-theme="light"`, or the OS setting when no script runs.
- `assets/prefs.js` — the theme (dark / light) and language (中文 / English) switches.
  Pages carry both languages (`lang="zh-CN"` / `lang="en"` pairs); Chinese is the default
  and the visitor's choice is remembered in localStorage.
- `mbti/` — the MBTI 16-type self-test page, generated by `build_site.py` in the local
  `mbti_self_test` workspace and copied here as `index.html` + `og.png` +
  `OFL-Anybody.txt`. Do not hand-edit; rebuild and copy again.
- `assets/pages.json` — short page names (`{path: [zh, en]}`) for the owner report,
  written by `tools/gen_notes.py`.
- `tools/gen_notes.py` — renders the note pages, the rail and `404.html` from an in-file
  post table. To add a post: edit the `POSTS` list (including its short name `short` /
  `zh.short`, at most 24 display columns) and run `python3 tools/gen_notes.py`, then add a
  matching row to the "Latest notes" list in `index.html`. A new tool page goes into
  `TOOLS` so the rail and the owner report name it. Tests: `python3 tools/tests/test_gen_notes.py`.
  Every post needs its Chinese version under `"zh"`; the script refuses to run without it.
- `plan_md_files/index_plan.md` — the design rationale.

Design notes live in `plan_md_files/`.
